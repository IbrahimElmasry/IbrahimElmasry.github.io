# Colophon

This portfolio is designed and maintained by Ibrahim Tarek to present his software projects, experience, and technical interests.

## Design and implementation

- Built with Blazor WebAssembly and .NET 8.
- Portfolio content is stored in JSON files and served as static assets.
- The dark interface, project illustrations, timeline, animated light trails, and responsive layouts are implemented with custom Razor, CSS, inline SVG, and JavaScript.
- Typography uses DM Sans, DM Mono, and Manrope from Google Fonts, with system fallbacks.
- GitHub Pages provides static hosting. The contact form posts to Formspree using the endpoint configured in `wwwroot/data/profile.json`.

## Contact and social links

The website footer reads GitHub, LinkedIn, email, and WhatsApp links from `wwwroot/data/profile.json`. The WhatsApp URL uses the international phone number in `wa.me` format.
